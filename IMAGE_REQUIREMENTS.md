## 📋 Image Specifications

- **Format**: JPG preferred (PNG, WebP, SVG also supported)
- **Size**: Recommended 400x300px or similar aspect ratio
- **Quality**: Good quality, clear representation of the style
- **Background**: Clean, professional background preferred
- **Orientation**: Portrait or square format works best

## 🔧 Alternative Formats

The system will try to find images in this order:
1. .webp
2. .jpg
3. .jpeg
4. .png
5. .svg

So you can use any of these formats, but make sure the filename matches exactly (e.g., `stubble.jpg`, `crew-cut.png`, etc.)

## ✅ How to Add Images

1. Download or gather images for each style
2. Rename them to match the exact filenames listed above
3. Place them in the corresponding folders:
   - Beard styles → `D:\barber-MS\static\images\haircut_styles\beard\`

   - Women's haircuts → `D:\barber-MS\static\images\haircut_styles\haircut_women\`

4. The images will automatically appear in your Browse Styles section!
